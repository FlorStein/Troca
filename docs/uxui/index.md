# UX/UI — Troca

## Principios de diseño
- Mobile-first
- Cálido y latinoamericano — cercano, no corporativo
- Concreto: mostrar ahorro real, no promesas vagas
- Confianza visible: perfiles verificados, reviews, fotos reales

## Tono visual
- No aspiracional europeo (eso es HomeExchange)
- Paleta de colores: a definir — cálida, mediterránea/latinoamericana
- Tipografía: a definir
- Fotografía: real, no stock — destinos ARG y Brasil

## Flujos críticos a diseñar primero
1. Onboarding y selección de plan
2. Búsqueda y detalle de hotel con beneficio
3. Publicación de propiedad
4. Solicitud de intercambio

## Design system
- A construir una vez definida identidad visual
- Componentes base: botones, cards de hotel, cards de propiedad, badges de plan
